# 精密加工车间 3D Demo

此页面是独立的浏览器端场景，保留仓库原有工厂应用。它用于展示机械零件加工车间的布局、物流和单件工艺路线，不连接真实机床、机器人或 AMR。

## 启动

在仓库根目录运行：

```bash
npm --prefix frontend run dev
```

打开终端显示的本地地址，并访问 `/workshop.html`。该页面不要求启动 Python 后端。

## 场景与操作

- 车间占地 48 × 30 m，包含原料、数控车削、加工中心、去毛刺、清洗、尺寸检验、返修、成品及维护等区域。
- 鼠标拖动旋转场景，滚轮缩放；左侧目录可搜索、筛选和选择设备。
- 选择左侧设备或场景物件后，镜头自动锁定到它的场景坐标并置于画面中央。机床聚焦时从前上方观察，并打开顶盖，可看见主轴、刀具和工作台动画；使用“等轴视角”或“俯视平面”返回全局。
- 设备铭牌和区域牌都是较大的平面标签，固定在地面场景坐标，不会跟随镜头转向。可通过“设备标签”切换显示。
- 两台上下料机械臂各安装在一条导轨上：R01服务三台车床，R02服务三台加工中心，并沿单元移动到机床前方。
- “工件流程”默认开启。AMR01载着同一个轴类工件，从原料交接点依次送到车削、加工中心、去毛刺、清洗、尺寸检验和成品区；到成品区卸货后空载返回。地面标出交接点和当前工序，底部显示承运状态与七道工序。AMR02继续在公共物流通道巡回。
- 到站后，AMR停靠，工件经卸载动画进入工位，在演示加工后重新装车；车削和加工中心的机械爪跟随工件完成交接。工件在车削、铣削后用不同外形表示工序进度。
- 点击“跟随工件”锁定工件本身，装卸与加工期间镜头继续跟随工件；点击“下一工序”快进到下一站到站前。移动中的AMR和导轨机器人被选中后，镜头会跟随其当前位置，仍可绕物件旋转和缩放。
- 底部控制可暂停、重置和调整演示速度；选中机床后可注入或恢复演示故障。

## 演示边界

机床刀具/工作台、AMR 和工件的运动是本地视觉演示。各站装卸和加工时长是为了观看设定，工件外形是预设工序示意，不计算刀路、材料去除、尺寸公差、质量判定或真实产能。工件回放和设备故障演示各自运行，不进行故障后的排程或物流改派。两台导轨机械臂展示一臂服务三机的布局，数量是否满足真实产能，还需结合机床加工节拍、装卸时间和导轨行程验证。
