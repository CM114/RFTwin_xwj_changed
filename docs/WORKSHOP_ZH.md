# 精密加工车间 3D Demo

此页面是独立的浏览器端场景，保留仓库原有工厂应用。它用于展示机械零件加工车间的布局、物流和单件工艺路线，不连接真实机床、机器人或 AMR。

## 启动

在仓库根目录运行：

```bash
npm --prefix frontend run dev
```

打开终端显示的本地地址，并访问 `/workshop.html`。该页面不要求启动 Python 后端。

## 场景与操作

- 车间占地 48 × 30 m，包含原料、数控车削、加工中心、去毛刺、清洗、尺寸检验、返修、成品及维护等区域。
- 鼠标拖动旋转场景，滚轮缩放；左侧目录可搜索、筛选和选择设备。
- 选择机床后点“聚焦设备”，进入近景并打开该机床顶盖，可观察主轴、刀具和工作台的演示动画。使用“等轴视角”或“俯视平面”返回全局。
- 设备铭牌和区域牌固定在场景中的位置，不会跟随镜头转向。可通过“设备标签”切换显示。
- “工件流程”默认开启，展示一个演示工件沿原料、车削、加工中心、去毛刺、清洗、尺寸检验到成品的完整路线；底部同步显示七个工序。
- 底部控制可暂停、重置和调整演示速度；选中机床后可注入或恢复演示故障。

## 演示边界

机床刀具/工作台、AMR 和工件的运动是本地视觉演示。工件标记沿流程路线循环移动，不表示真实加工节拍；没有模拟刀路、材料去除、尺寸公差、质量判定或真实产能。故障、设备状态和时间线也都是本地状态，不代表真实设备数据。
